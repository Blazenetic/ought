# Ought

A focused pure-Python library of the missing practical batteries.

Ought provides three tightly-scoped, high-quality utilities that most real programs need:

1. **Hierarchical configuration** (`ought.settings`)
2. **Lightweight structured concurrency helpers** (`ought.nursery`)
3. **Ordered multi-maps** (`ought.multimap`)

Pure Python, zero (or near-zero) hard dependencies, documentation-first, and small enough to vendor without guilt.

**Status:** Design proposal — ready for implementation planning.

See the full design proposal: [docs/library-proposal.md](docs/library-proposal.md)
